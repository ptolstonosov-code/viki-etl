### Адаптация под РФ-сеть (DPI-блокировки)
ARM-устройства пользователя в России → deb.debian.org и pypi.org (Fastly) блокируются.
Решено:
- **apt**: `arm_install.sh` авто-определяет недоступность deb.debian.org
  (curl с таймаутом 8с) и переключается на `mirror.yandex.ru` + ForceIPv4.
- **pip**: в пакет вложены 15 aarch64/cp39 wheels (`wheels/`), установка
  `--no-index --find-links` полностью offline. Архитектурно-зависимые
  `pydantic_core` и `pyyaml` — под manylinux2014_aarch64/cp39 (проверено).
- **llama.cpp**: исходники в пакете, компилируются на устройстве (github не нужен).
- **модель .gguf**: в пакете.
Итог: на ARM нужен интернет только для apt (через РФ-зеркало), всё остальное offline.

  orchestrator.py            main entry: ingest_file + tick

  api_service.py             FastAPI :8080 — main HTTP API

  systemd/                   ← 4 unit-файла
    llm-etl.target           supergroup
    llm-etl-api.service      always-on, ~150 MB RAM
    llm-etl-viewer.service   always-on, ~100 MB RAM
    llm-etl-llm.service      on-demand, ~1.5 GB RAM, idle 60s → auto-stop

## ✅ Сделано

### Архитектура и код
- 40+ таблиц SQLite (`config/schema.sql`)
- `core/llm_client.py` — клиент с тремя backend'ами: `none`, `llama_server` (HTTP), `hf`, `ollama`
- `core/data_parser.py` — детект формата + чанкинг
- `core/db_writer.py` — запись через SQLAlchemy с conflict-strategy
- `core/parsers/commerceml.py` — детерминированный парсер 1С CommerceML 2.05
- `training/dataset_builder.py` — JSONL → HF Dataset с chat-форматом
- `training/finetune.py` — QLoRA / full LoRA через trl 1.x (адаптивно — работает с разными версиями SFTConfig/SFTTrainer)
- `training/annotation.py` — schema-validate + bootstrap из парсера
- `training/continual.py` — incremental learning с replay buffer 20%
- `training/evaluate.py` — F1 per table/field
- `ui/app.py` — Gradio UI: разбор, разметка, fine-tune, настройки (на русском)
- `main.py` — CLI: init-db / parse / ingest / train / train-continual / evaluate / bootstrap-1c / ui

- `gpu_host/2_train.sh` — запуск fine-tune
- `gpu_host/3_export_gguf.sh` — merge LoRA + GGUF f16 + Q4_K_M
- `target_host/target_install.sh` — компиляция llama.cpp под ARM, systemd
